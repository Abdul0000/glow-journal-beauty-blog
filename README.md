# Glow Journal
A responsive editorial beauty blog for skincare, makeup, haircare and everyday wellness.

## Features
- Editorial homepage with image-led hero and latest stories
- Static-generated story pages, About page and custom 404
- Responsive layout, accessible form labels and reduced-motion support
- No backend secrets required

## Run
```bash
pnpm install
pnpm dev
```

The newsletter form currently demonstrates front-end interaction only. Connect an email provider before collecting subscriptions in production. Images load from Unsplash.
